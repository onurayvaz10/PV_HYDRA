# Amendment 1 to the revision protocol (2 October 2026; the commit time is the record)

Recorded while the runs of P1–P5 were in progress; no rate of P3–P6 had been inspected.

1. **P4, listed coefficient.** Manufacturer datasheets were not retrieved for every installed module. The
   coefficient of the installed module is therefore taken from the CEC module database distributed with pvlib
   (`gamma_r`), where the module model given on the DKA Solar Centre array page is listed (DKASC 7, 10, 14 and 18).
   It is reported as the *listed* coefficient, not as a datasheet value.
2. **P4, clear-sky workflow.** The records are hourly; the pvlib clear-sky detection of RdTools needs sub-hourly
   windows, so the clear-sky-index filter (`model = "csi"`) is used. Alice Springs is localized to the IANA zone
   Australia/Darwin (UTC+9:30, no daylight saving).
3. **Reference window.** The sensitivity of the two-stage rate to the 24-month reference window (XGBoost, months
   1–24, 13–36 and 25–48, five seeds) is recomputed on the 18 main systems with the fixed hour mask of P1, so that
   every measured number of the paper uses the same records, hygiene and mask.
4. **Latitude.** The rank correlation between the site-level reference error and absolute latitude is computed over
   the 20 weather sites (independent units: sites).
