# Amendment 3 to the revision protocol (3 October 2026; the commit time is the record)

Recorded after an internal review of the full results, before the runs listed under 4–6.

1. **Common rate convention for known-rate records.** All estimators report rates relative to the first-year level
   (t = 0.5 yr); the generators define their rate relative to the starting level. Every known-rate record is re-scored
   against truth / m(0.5), with m the generator's trend factor (linear generators: r / (1 + r/200), e.g. −1.0050 %/yr
   for r = −1 %/yr). No model is refitted (`src/degradation/truth_convention.py`, `scripts/rescore_first_year.py`).
   The injection experiment already uses this convention through Eq. (2).
2. **Hourly validity rule.** An hour is kept when at least 90 % of its native intervals hold a valid power sample
   (count of valid samples; the earlier code counted rows). On the 18 main systems both rules keep identical hours and
   identical reference rates (`scripts/check_hourly_rule.py`, `R10_hourly_rule.csv`).
3. **Leave-one-location-out summary** of the injected-change errors (computed from the existing runs).
4. **Interval sensitivity to serial dependence.** Reference YoY interval with the circular block bootstrap (30-day
   blocks) besides the default bootstrap, 18 main systems (`scripts/run_block_bootstrap.py`).
5. **Input-length control.** XGBoost on the same 24-h input window as the sequence models (`xgboost_w24`), injection
   experiment (fixed mask, 5 seeds) and the 240 exact-rate records of the 20 weather sites.
6. **Simple-correction control.** κ-HYDRA-D with a linear correction g = 1 + 0.5 tanh(linear(x)) and the same joint
   trend (`linear_correction`), injection experiment (5 seeds) and the 240 exact-rate records.

Every result of 4–6 is reported whatever it shows.
